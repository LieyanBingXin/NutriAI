## Slide 3 · 核心设计思路：为什么不全靠 AI？

```
三个硬约束决定了我们必须"规则优先"

  约束 1：效率
    "今天 68kg" → 发 AI（1-3 秒 + API 费用）
    → 正则解析 < 100ms，零成本
    15 种意图能覆盖 80% 日常操作

  约束 2：准确
    自然语言歧义太多
    "我家有鸡蛋" → 到底是"存冰箱"还是"推荐做法"？
    → 关键词能精准区分

  约束 3：安全
    AI 直接操作数据库有 prompt injection 风险
    → 规则层做安全边界，AI 只负责生成自然语言回复

我们的方案：

  用户输入
     │
     ├── 能被规则解析 → 直接执行 → 返回结果（< 100ms）
     │    覆盖率 ~80%：体重、冰箱、偏好、查询...
     │
     └── 规则搞不定 → 带完整上下文发给 AI → 流式自然语言
          覆盖率 ~20%："制定减脂计划""分析我的饮食结构"

  核心价值：快的事不花钱，难的事才动 AI
```

## Slide 6 · 关键技术：体重提取三层正则

```
为什么是三层？"今天吃了 200g 牛肉，刚称 68kg"

  问题："200g" 和 "68kg" 都有数字+单位，正则容易误匹配

  Layer 1 — 宽松正则（先捞所有候选项）
    匹配模式：数字 + (kg|公斤|斤|两)
    → "200g" → g 不在体重单位列表，跳过
    → "68kg" → 命中，暂保留 ✓

  Layer 2 — 反排除（去掉假阳性）
    检查数字前面的语境：
    ├─ 前有食材量词（g/克/份/碗/个）→ 这是食物重量，排除
    │  "200g 牛肉" 前面有单位 → 排除 ✓
    ├─ 前有价格词（¥/元/块）→ 排除
    └─ 数值范围验证（20-200 kg 之间才算合理）

  Layer 3 — 关键词兜底（可信度最高）
    前文含体重关键词（体重/称了/刚称/kg）
    → "刚称 68kg" → 确认 ✓

配套：相对日期解析
  "今天 68kg"    → LocalDate.now()
  "昨天 68kg"    → minusDays(1)
  "大前天 68kg"  → minusDays(3)
  "3 天前 68kg"  → minusDays(3)
```

## Slide 8 · AI 营养提醒区块（第七周新增）

```
为什么要单独一个分区？因为它和其他便利贴完全不同

  来源     其他四个分区：用户手动添加               AI 提醒：系统自动计算
  数据     喜好/厌恶/冰箱/角色标签                 营养缺口（近 N 天饮食分析）
  交互     点击标签 → 发送给 AI                    纯展示，不可点击
  样式     实线边框 + 纯色背景                     虚线边框 + 紫粉渐变 + 顶部渐变条

设计细节：

  ┌─ 顶部 4px 渐变条（紫 → 粉）────────────────┐
  │  🧠 AI 营养提醒                            │
  │                                            │
  │  📊 近 7 天：12 餐记录                      │
  │                                            │
  │  热量    ████████████░░░░░░░░  60%  偏低   │
  │  蛋白质  ████████████████░░░░  80%  正常   │
  │  碳水    ████████████████░░░░  80%  正常   │
  │  脂肪    ██████████░░░░░░░░░░  50%  偏低   │
  │  膳食纤维 ██░░░░░░░░░░░░░░░░░░  20%  严重不足│
  │  ⚠️ 钙     ████░░░░░░░░░░░░░░░░  20%  严重不足│
  │                                            │
  │  ┌─ 💡 AI 洞察 ────────────────────────┐  │
  │  │ 你最近的蔬菜摄入明显偏少，膳食纤维     │  │
  │  │ 已经连续 5 天低于推荐值。建议今天     │  │
  │  │ 中午加一份深色蔬菜（西兰花/菠菜），   │  │
  │  │ 晚餐可以用杂粮代替白米饭。            │  │
  │  └──────────────────────────────────────┘  │
  └────────────────────────────────────────────┘

技术实现：
  · 后端 /api/assistant/board 返回 gap 字段
  · gap.nutrientGaps[] — 每个营养素的 实际值 / 目标值 / 百分比 / 状态
  · gap.aiInsight — AI 生成的自然语言洞察文字
  · 缺口等级：严重不足 < 40%（红色）→ 偏低 < 80%（橙色）→ 正常 < 110%（绿色）
  · 无记录时显示引导语："先去记几餐饮食，AI 才能看到缺口"
```

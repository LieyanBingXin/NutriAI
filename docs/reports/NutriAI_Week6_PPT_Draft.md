## Slide 3 · 核心设计思路

```
为什么不全靠 AI？三个硬约束

  约束 1：效率
    "今天 68kg" → 发 AI（1-3 秒 + 花钱）？
    → 正则解析 < 100ms，零成本
    15 种意图能覆盖 80% 日常操作

  约束 2：准确
    自然语言歧义太多
    "我家有鸡蛋" → 到底是"存冰箱"还是"推荐做法"？
    → 关键词能精准区分

  约束 3：安全
    AI 直接操作数据库有 prompt injection 风险
    → 规则层做安全边界，AI 只负责生成自然语言回复

我们的方案：规则优先，AI 兜底

  用户输入
     │
     ├── 能被规则解析 → 直接执行 → 返回结果（< 100ms）
     │
     └── 规则搞不定 → 带完整上下文发给 AI → 返回自然语言

  规则层覆盖 80%（快、准、省、安全）
  AI 层 覆盖 20%（灵活、智能）
```

## Slide 6 · 关键技术：体重提取三层正则

```
为什么要三层？因为"今天 68kg" 和 "200g 牛肉" 里都有数字+单位

  用户输入: "今天吃了 200g 牛肉，刚称 68kg"
  期望: 提取 68kg（不是 200g）

三层递进：

  Layer 1 — 宽松正则（先抓所有可能）
    匹配所有数字 + 体重单位（kg/公斤/斤/两）
    先命中 "200g" → "g" 不在列表，跳过
    再命中 "68kg" → 暂时保留 ✓

  Layer 2 — 反排除（去掉假阳性）
    检查前面的文字：
    ├─ 前面是食材量（g/克/份/碗/个）→ 排除
    │  "200g 牛肉" 前面有食材量 → 排除 ✓
    ├─ 前面是价格（¥/元/块）→ 排除
    └─ 合理范围验证（20-200 kg）

  Layer 3 — 关键词兜底（最可信）
    前面有明确体重关键词（体重/称了/刚称）
    "刚称 68kg" → 最可信 ✓

配套：相对日期解析
  "今天 68kg"   → 今天
  "昨天 68kg"   → 昨天
  "大前天 68kg" → 3 天前
  "3 天前 68kg" → 3 天前
```

## Slide 8 · 关键技术：JSON 引号嵌套爆炸

```
这是一个经典的"拼接 HTML + JSON"陷阱

  问题：
    动态生成点击事件时：
    onclick="dropSticker("我喜欢 番茄")"
                        ↑ 这里就被截断了！
    外层双引号被内层 JSON 的双引号提前关闭
    → 所有看板标签点击静默失败

  为什么一开始没发现？
    只有当内容含双引号时才触发
    普通中文 "番茄" 不会触发
    但后来全文件重写后，所有动态 HTML 都带 JSON.stringify
    → 7 个 onclick × 3 个 onkeydown × 2 个 onload 全炸

  修复：两步走
    ① 加转义函数 escAttr() 处理特殊字符
    ② 所有 inline 改用单引号包裹：
       onclick='dropSticker("我喜欢 番茄")'
                ^^^^^^ 内层 JSON 双引号
       ^^^^^^^^ 外层 HTML 单引号 → 互不干扰

  教训：动态生成 HTML 属性时，引号处理是第一优先级
```

## Slide 9 · Bug 修复清单

```
本周开发踩了 7 个坑，全部修复

  🔴 功能阻断类（改完才能继续写功能）

  ① assistant.js 全文件编码损坏
     症状：所有中文变成 "鎴戝枩娆?"
     根因：工具链编码错乱
     修复：完全重写为干净 UTF-8

  ② JSON.stringify 双引号嵌套爆炸
     症状：看板所有标签点击/删除/添加全部静默失败
     根因：动态生成 onclick 引号嵌套
     修复：escAttr() 转义 + 单引号包裹（见 Slide 8）

  ③ DOM 初始化缺失
     症状：页面加载后便利贴完全不渲染
     根因：只定义了函数但没调用
     修复：加 DOMContentLoaded 显式调用

  🟡 构建/部署类

  ④ escAttr / escHtml 函数混用 → 新增独立 escAttr()

  ⑤ 导航栏遮挡页面 → 改为 fixed padding-top: 140px

  ⑥ Maven clean 失败 → 旧 Java 进程占用文件，杀掉即可

  ⑦ 刷新修改不生效 → 改 frontend/ 再同步到 static/

踩坑心得：
  · 工具链编码稳定比功能本身更重要
  · 动态生成 HTML 属性，引号是第一优先级
  · start.bat 同步逻辑是核心约束，改文件之前先搞清楚
```

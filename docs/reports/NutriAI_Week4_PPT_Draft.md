## Slide 3 · API 接口一览

```

─────────────────────────────────────────────────

PUT      /api/food-diary/{id}         修改日记
DELETE   /api/food-diary/{id}         删除日记

营养汇总（核心新增）
─────────────────────────────────────────────────
GET      /api/food-diary/daily        每日汇总 + 达标率 ⭐
GET      /api/food-diary/weekly       最近 7 天汇总 ⭐

用户画像 & AI 推荐
─────────────────────────────────────────────────
PUT      /api/user/profile            含地区 / 营养目标
POST     /api/recommend               流式 AI 推荐
```

## Slide 4 · 达标率核心逻辑

```
计算规则

  达标率 = 实际摄入 ÷ 目标值 × 100%
  目标值未设置 → 该营养素不展示

前端进度条可视化

  热量   ████████████░░░░░░░░░░  53.5%   (未满)
  蛋白质 ████████████████████████ 100.0%  ✅
  碳水   ████████░░░░░░░░░░░░░░░  36.0%   (偏低)
  脂肪   █████████████░░░░░░░░░░  55.4%   (未满)

  超 100% → 进度条变红 + 警示标签

示例数据

┌─────────┬───────────┬───────────┬────────┐
│ 营养素   │ 实际摄入   │ 目标值     │ 达标率  │
├─────────┼───────────┼───────────┼────────┤
│ 热量     │ 1070 kcal │ 2000 kcal │  53.5% │
│ 蛋白质   │ 80 g      │ 80 g      │ 100.0% │ ✅
│ 碳水     │  90 g     │ 250 g     │  36.0% │
│ 脂肪     │  36 g     │  65 g     │  55.4% │
└─────────┴───────────┴───────────┴────────┘
```

## Slide 5 · 7 天周汇总接口

```
GET /api/food-diary/weekly?endDate=2026-10-15

特点：
  • 固定返回 7 天，不管哪天有没有记录
  • 每天附带营养目标 + 达标率
  • 方便前端做柱状图展示

示意

  10-09    10-10    10-11    10-12    10-13    10-14    10-15
    0        0        0        0        0       晚餐     早+午
                         ↑ 没记录也补零，前端不用特殊处理
```

## Slide 6 · 地域特色推荐

```
用户资料新增「所在地区」字段 → AI Prompt 自动融入

前端表单 → 用户选择地区
     ↓
后端保存到 UserProfile.region
     ↓
AI 推荐时 Prompt 自动拼接：
  "该用户所在地区为 [广东广州]，
   推荐食谱时请优先融入当地特色食材和烹饪风格"

实际效果示例

  广东广州用户  → 清蒸鲈鱼、白灼菜心、老火靓汤、粤式粥品
  四川成都用户  → 凉拌鸡胸、番茄牛腩（微辣）、夫妻肺片（轻量版）
  陕西西安用户  → 羊肉萝卜汤、杂粮饭、凉拌菜
```
